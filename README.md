Repositório criado para a entrega da atividade prática da unidade curricular de Linguagem de Marcação do curso Técnico em Desenvolvimento de Sistemas no SENAI.

📌 Sobre o Projeto
O objetivo desta atividade é analisar a aplicação prática de conceitos de Tipografia e Cores no web design, identificando boas e más práticas de UX/UI, como contraste, hierarquia visual e harmonia de paletas.
